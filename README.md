# Prohibition Drinks

Modern, non-WordPress rebuild of the Prohibition Drinks website.

## Stack

- Next.js 16.3.8
- React 19.3
- TypeScript
- CSS
- Vercel-ready

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production

```bash
npm run build
npm start
```

The project is designed for direct deployment to Vercel.

## Migration note

This codebase replaces the previous WordPress / Visual Composer landing page with a native Next.js implementation. Original Prohibition Drinks brand assets recovered from the WordPress uploads library are stored in `public/images`.
